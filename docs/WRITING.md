# نوشتنِ مقاله

یک فایل دست می‌خورد: [`src/data/articles.ts`](../src/data/articles.ts).

صفحه، کارت، فهرستِ مطالب، سایدبار، چیپِ فیلتر، مطالبِ مرتبط و
`sitemap.xml` همه خودشان از همان آرایه ساخته می‌شوند.

---

## کوتاه‌ترین مقاله‌ی ممکن

```ts
article({
  slug: 'my-article',
  title: 'عنوان',
  excerpt: 'یک جمله که روی کارت دیده می‌شود.',
  topic: 'gaming',
  publishedAt: '۳۰ شهریور ۱۴۰۵',
  body: [
    p('پاراگراف.'),
    h('یک تیتر'),
    p('پاراگرافِ دیگر.'),
  ],
}),
```

همین. `article({...})` را پیش از `];` در آرایه‌ی `RAW` بگذار.

---

## چیزهایی که خودت نمی‌نویسی

| فیلد | از کجا می‌آید |
|---|---|
| `readMinutes` | از تعدادِ کلمه‌ها، ۲۰۰ کلمه در دقیقه |
| `topicLabel` | از `topic` |
| `accent` | از `topic` |
| لنگرِ تیترها | از متنِ خودِ تیتر |
| فهرستِ مطالب | از تیترهای `h` و `h3` |

⚠ **زمانِ مطالعه را نمی‌شود دستی نوشت، و این عمدی است.** چهار
مقاله‌ی اولِ سایت هفت تا یازده دقیقه ادعا می‌کردند و واقعاً یک تا
دو دقیقه بودند. روی سایتی که حرفش اعتماد است، این عدد نباید دروغ
بگوید.

## همه‌ی بلوک‌ها

از [`src/data/articleKit.ts`](../src/data/articleKit.ts) وارد می‌شوند.

```ts
p('پاراگراف.')

h('تیترِ بخش')          // در فهرستِ مطالب می‌آید
h3('زیرتیتر')           // تورفته در فهرست

ul(['یک', 'دو'])        // نقطه‌ای
ol(['اول', 'دوم'])      // شماره‌دار

note('نکته‌ی خنثی.')     // آبی
tip('پیشنهاد.')          // سبز
warn('حواست باشد.')      // نارنجی

quote('نقلِ برجسته.', 'گوینده')   // گوینده اختیاری است

img('/path/pic.webp', 'زیرنویس')

table(
  ['', 'ستون الف', 'ستون ب'],
  [
    ['ردیف یک', 'الف', 'ب'],
    ['ردیف دو', 'الف', 'ب'],
  ],
)

steps([
  { t: 'گامِ اول', d: 'شرح.' },
  { t: 'گامِ دوم', d: 'شرح.' },
])

faq([
  { q: 'سوال؟', a: 'جواب.' },
])

product('battlefield-6', 'یک جمله‌ی تشویقی.')  // کارتِ محصول

hr()                    // خطِ جداکننده
```

### `product()` را جدی بگیر

هیچ‌کدام از چهار مقاله‌ی اولِ سایت **حتی یک لینک** به صفحه‌ی
محصول نداشتند. یعنی خواننده قانع می‌شد و بعد هیچ مسیری جلویش
نبود.

فقط `slug` را می‌دهی؛ عنوان، تصویر و قیمت سرِ رندر از کاتالوگ
خوانده می‌شوند — پس مقاله هیچ‌وقت قیمتِ کهنه نشان نمی‌دهد. اگر
محصول حذف شود، کارت اصلاً رندر نمی‌شود (لینکِ شکسته وسطِ مقاله
از نبودنش بدتر است).

محصولاتی که با `product()` نام برده شوند، خودکار در سایدبار هم
می‌آیند.

## موضوع‌ها

چهارتا، و بیشتر نمی‌شود بی‌آنکه در `articleKit.ts` تعریف شود:

| `topic` | برچسب | رنگ |
|---|---|---|
| `ai` | هوش مصنوعی | بنفش |
| `gaming` | گیم | آبی |
| `creative` | طراحی و ادیت | صورتی |
| `guide` | راهنما | سبز |

## کاور

```ts
cover: '/hero/banner/battlefield-6-wide.webp',
coverWide: true,
```

⚠ **`coverWide` را جدی بگیر.** قابِ کارت ۱۶:۹ است. تصویرِ مربع
(مثل لوگوی محصول) اگر `coverWide: true` بگیرد بریده می‌شود و از
لوگو فقط نوارِ میانی می‌ماند. برای تصویرِ مربع، خطِ `coverWide` را
کلاً ننویس.

تصویرهای موجود: `public/hero/banner/` (پهن) · `public/products/`
و `public/games/` (مربع).

## بعد از نوشتن

```bash
npm run build:host
```

`slug` تکراری یا `topic` اشتباه همین‌جا خطا می‌دهد.

## نمونه‌ی کامل

مقاله‌ی `steam-full-account-vs-key` در ابتدای `articles.ts` **هر
نوع بلوک را دقیقاً یک بار** دارد. اگر خواستی ببینی `table` یا
`steps` چطور نوشته می‌شود، همان‌جا جلوی چشم است.

## وقتی وردپرس آمد

همین شکلِ داده از WP REST پر می‌شود و کامپوننت‌ها دست نمی‌خورند.
یعنی مقاله‌هایی که الان این‌جا می‌نویسی، بعداً یک بار باید به
وردپرس منتقل شوند.

برای دو سه مقاله، همین راه سریع‌تر است. برای ده‌تا، شاید بهتر
باشد صبر کنی.
