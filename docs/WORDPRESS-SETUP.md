# وردپرس، ووکامرس و افزونه‌ها — قدم به قدم

> این سند برای *کلیک کردن* است. معماری و دلیلِ این معماری در
> [BACKEND.md](BACKEND.md) نوشته شده؛ این‌جا فقط ترتیبِ کارهاست.

⏱ مجموعاً حدود **دو تا سه ساعت**، به‌جز وارد کردنِ محصولات و
گرفتنِ درگاه.

---

## پیش از شروع: یک قاعده

⚠ **هر افزونه‌ای که نصب می‌کنی، یک درِ تازه به فروشگاهت است.**

این سایت قرار است پول جابه‌جا کند. بیشترِ هکِ سایت‌های وردپرسی
از خودِ وردپرس نیست، از افزونه‌ای است که کسی سه سال پیش نصب
کرده و دیگر به‌روز نمی‌شود.

پس قاعده: **اگر مطمئن نیستی لازم است، نصبش نکن.** فهرستِ ته این
سند عمداً کوتاه است.

## گام ۱ — زیردامنه (۵ دقیقه)

دایرکت‌ادمین ‹ **Subdomain Management** ‹ افزودن:

```
panel
```

یعنی `panel.phonixmarket.com`.

⚠ **اسمش را `shop` نگذار.** دایرکت‌ادمین زیردامنه را داخلِ
`public_html` می‌سازد، و خودِ سایت صفحه‌ی `/shop/` دارد. یکی روی
دیگری می‌افتد. اسم‌های امن: `panel` · `api` · `my`.

فهرستِ کاملِ اسم‌هایی که تصادم دارند در [HOST.md](HOST.md) است.

---

## گام ۲ — SSL برای زیردامنه (۵ دقیقه)

دایرکت‌ادمین ‹ **SSL Certificates** ‹ Let's Encrypt ‹ برای
`panel.phonixmarket.com`.

⚠ این را **قبل** از نصبِ وردپرس بگیر. اگر وردپرس روی `http` نصب
شود، آدرسِ سایت در پایگاه داده با `http` ذخیره می‌شود و بعداً
عوض کردنش دردسر دارد.

---

## گام ۳ — نصبِ وردپرس (۱۵ دقیقه)

دایرکت‌ادمین ‹ **Installatron** یا **Softaculous** ‹ WordPress ‹ Install.

| فیلد | مقدار |
|---|---|
| Domain | `https://panel.phonixmarket.com` |
| Directory | **خالی بگذار** |
| Site Name | پنل فونیکس شاپ |
| Admin Username | **نه `admin`** — یک اسمِ دیگر |
| Admin Password | طولانی، از تولیدکننده‌ی رمز |
| Language | فارسی |

⚠ **`admin` ننویس.** نصفِ حمله‌های خودکار روی وردپرس، همین یک
نام را با هزار رمز امتحان می‌کنند. اسمِ دیگر، آن حمله را از
همان اول بی‌اثر می‌کند.

⚠ **Directory را خالی بگذار** وگرنه وردپرس در
`panel.phonixmarket.com/wordpress/` می‌افتد.

## گام ۴ — تنظیماتِ اولِ وردپرس (۱۰ دقیقه)

وارد `panel.phonixmarket.com/wp-admin` شو.

### پیوندهای یکتا — مهم‌ترین تنظیم

**تنظیمات ‹ پیوندهای یکتا ‹ نام نوشته** (`/%postname%/`)

⚠ بدونِ این، **REST APIِ ووکامرس درست کار نمی‌کند** و سایتِ
استاتیک نمی‌تواند محصولات را بخواند. این اولین چیزی است که باید
عوض شود، نه آخرین.

### بقیه

- **تنظیمات ‹ همگانی** → منطقهٔ زمانی: `Asia/Tehran`
- **تنظیمات ‹ خواندن** → تیکِ «از موتورهای جست‌وجو بخواه…» را
  **بزن**. این پنلِ داخلی است و نباید در گوگل باشد.
- **تنظیمات ‹ گفتگو** → دیدگاه‌ها را ببند. فروشگاه وبلاگ نیست و
  دیدگاهِ باز یعنی سیلِ اسپم.
- **کاربران ‹ شناسنامه** → اگر کاربرِ `admin` ساخته شده، حذفش کن.

## گام ۵ — ووکامرس (۲۰ دقیقه)

**افزونه‌ها ‹ افزودن ‹ WooCommerce ‹ نصب و فعال‌سازی**

جادوگرِ راه‌اندازی می‌آید. جواب‌ها برای فروشگاهِ دیجیتال:

| سوال | جواب |
|---|---|
| نوع صنعت | سایر / دیجیتال |
| نوع محصول | **محصولات دانلودی** |
| فروش حضوری؟ | خیر |
| افزونه‌های پیشنهادی | **همه را رد کن** |

⚠ آن مرحله‌ی «افزونه‌های پیشنهادی» چهار پنج افزونه‌ی بازاریابی
نصب می‌کند که هیچ‌کدام به کارت نمی‌آیند. رد کردنشان کارِ بعداً
را کم می‌کند.

### تنظیماتِ ووکامرس که واقعاً مهم‌اند

**ووکامرس ‹ تنظیمات ‹ همگانی**

- واحدِ پول: **تومان ایران (IRT)** — ووکامرس خودش دارد، افزونه
  نمی‌خواهد
- تعدادِ اعشار: **۰** (تومان اعشار ندارد)
- جداکنندهٔ هزارگان: `,`
- فعال‌سازیِ نرخِ مالیات: **خاموش**

**ووکامرس ‹ تنظیمات ‹ محصولات**

- واحدِ وزن و ابعاد: بی‌اهمیت، دست نزن
- مدیریتِ موجودی: **روشن** (افزونه‌ی ما برای کدهای انبار لازمش دارد)

**ووکامرس ‹ تنظیمات ‹ حساب‌ها**

- «اجازهٔ سفارش بدونِ حساب»: **روشن**
- «اجازهٔ ساختِ حساب هنگامِ تسویه»: **روشن**

⚠ **حمل‌ونقل** را کلاً نادیده بگیر. محصولِ دانلودی حمل ندارد و
اگر روشن بماند، سرِ تسویه از مشتری آدرسِ پستی می‌خواهد.

## گام ۶ — افزونه‌ی فونیکس (۵ دقیقه)

فایل: `wp-plugin/releases/phoenix-bridge-1.1.0.zip`

**افزونه‌ها ‹ افزودن ‹ بارگذاری افزونه ‹ همین فایل ‹ فعال‌سازی**

بعد از فعال‌سازی، منوی **فونیکس** در نوارِ کناری می‌آید.

⚠ **موتورِ قیمت خاموش فعال می‌شود، و این عمدی است.** افزونه‌ای
که به‌محضِ نصب قیمتِ کلِ فروشگاه را عوض کند ترسناک است. اول
محصولات را وارد کن، بعد روشنش کن.

### ترتیبِ درستِ روشن کردن

۱. **فونیکس ‹ نرخ** ‹ «همین حالا دوباره بگیر» — ببین نرخ می‌آید
۲. **فونیکس ‹ حاشیه و قیمت** ‹ درصدِ سود را تنظیم کن
۳. چند محصول با قیمتِ تمام‌شده وارد کن
۴. همان صفحه ‹ **پیش‌نمایشِ زنده** ‹ ببین قیمت‌ها چه می‌شوند
۵. اگر درست بود → **فونیکس ‹ داشبورد** ‹ موتور را روشن کن

قدمِ ۴ را رد نکن. پیش‌نمایش برای همین هست.

## گام ۷ — کرونِ واقعی (۵ دقیقه)

⚠ **بدونِ این، نرخِ تتر ساعتی به‌روز نمی‌شود.**

کرونِ وردپرس با *بازدید* اجرا می‌شود، نه با ساعت. روی پنلی که
فقط تو واردش می‌شوی، یعنی ممکن است روزها هیچ به‌روزرسانی‌ای
نشود.

**۱ — در `wp-config.php` (از File Manager):**

```php
define('DISABLE_WP_CRON', true);
```

پیش از خطِ `/* That's all, stop editing! */` بگذارش.

**۲ — دایرکت‌ادمین ‹ Cron Jobs ‹ افزودن:**

| فیلد | مقدار |
|---|---|
| Minute | `*/5` |
| بقیه | `*` |
| Command | `curl -s https://panel.phonixmarket.com/wp-cron.php?doing_wp_cron > /dev/null` |

هر پنج دقیقه. نرخ ساعتی گرفته می‌شود ولی کارهای دیگر (بازنویسیِ
دسته‌ایِ قیمت، صف) تندتر لازمشان است.

## گام ۸ — کلیدِ اتصال به سایت (۱۰ دقیقه)

**ووکامرس ‹ تنظیمات ‹ پیشرفته ‹ REST API ‹ افزودن کلید**

| فیلد | مقدار |
|---|---|
| توضیح | سایت استاتیک |
| کاربر | حسابِ مدیر |
| دسترسی | **فقط خواندن** |

⚠ **«فقط خواندن»، نه «خواندن و نوشتن».** سایتِ استاتیک فقط
کاتالوگ را می‌خواند. کلیدِ نوشتن اگر لو برود یعنی کسی می‌تواند
محصول و قیمت را عوض کند.

کلید و رمز را **همان لحظه** کپی کن؛ رمز دیگر نشان داده نمی‌شود.

بعد در پروژه، فایلِ `.env.local`:

```
WORDPRESS_URL=https://panel.phonixmarket.com
WOO_CONSUMER_KEY=ck_...
WOO_CONSUMER_SECRET=cs_...
NEXT_PUBLIC_BRIDGE_URL=https://panel.phonixmarket.com/wp-json/phoenix/v1
```

⚠ **این فایل هیچ‌وقت به گیت نمی‌رود.** سه تای اول فقط سرِ بیلد
روی کامپیوترِ خودت خوانده می‌شوند. فقط `NEXT_PUBLIC_BRIDGE_URL`
داخلِ فایل‌های سایت می‌رود — و آن هم اندپوینتِ عمومیِ
فقط‌خواندنی است.

دلیلِ کاملش در بالای [`src/lib/api/config.ts`](../src/lib/api/config.ts).

## گام ۹ — درگاهِ پرداخت

⚠ **این طولانی‌ترین انتظار است: ۱ تا ۷ روزِ کاری.** درگاه بدونِ
نمادِ اعتماد یا حداقل مدارکِ هویتی وصل نمی‌شود.

**همین امروز پرونده‌اش را باز کن**، حتی اگر بقیه‌ی کارها تمام
نشده. هرچه دیرتر شروع شود، فروشگاه دیرتر واقعی می‌شود.

درگاه‌های رایج: زرین‌پال · آیدی‌پی · نکست‌پی · زیبال

هر کدام افزونه‌ی ووکامرسِ خودشان را دارند و بعد از تأییدِ
پرونده، فایل و راهنمایش را می‌دهند. **پیش از تأیید، افزونه‌شان
را نصب نکن** — کاری نمی‌کند و فقط یک افزونه‌ی بی‌مصرف است.

## افزونه‌ها — کوتاه‌ترین فهرستِ ممکن

### لازم

| افزونه | برای چه |
|---|---|
| **WooCommerce** | خودِ فروشگاه |
| **Phoenix Bridge** | مالِ خودمان — قیمت، تخفیف، سفارش |
| **افزونه‌ی درگاه** | بعد از تأییدِ پرونده |

### احتمالاً لازم

| افزونه | برای چه | نکته |
|---|---|---|
| **تاریخِ شمسی** (WP Jalali یا مشابه) | تاریخِ سفارش‌ها شمسی شود | فقط اگر تاریخِ میلادی اذیتت می‌کند |
| **UpdraftPlus** | پشتیبانِ خودکار | ⚠ این یکی واقعاً مهم است |

### نصب نکن

- افزونه‌های «بهینه‌سازی سرعت» — سایتِ اصلی استاتیک است، پنل
  سرعت نمی‌خواهد
- افزونه‌های سئو (Yoast و…) — پنل نباید در گوگل باشد
- افزونه‌های کش — با REST API تداخل می‌کنند و کاتالوگِ کهنه
  به سایت می‌دهند
- هر افزونه‌ای که آخرین به‌روزرسانی‌اش بیش از یک سال پیش است
- افزونه‌های صفحه‌ساز (المنتور و…) — این‌جا صفحه‌ای ساخته
  نمی‌شود

⚠ **پشتیبان را جدی بگیر.** افزونه‌ی فونیکس سه جدول و تنظیمات
دارد؛ برگرداندنشان بدونِ پشتیبان ممکن نیست. UpdraftPlus را روی
پشتیبانِ روزانه تنظیم کن.

## امنیت — پنج چیزِ کوچک که واقعاً اثر دارند

۱. نامِ کاربریِ مدیر `admin` نباشد ✔ (گام ۳)
۲. رمزِ طولانی، و **ورودِ دومرحله‌ای** اگر افزونه‌اش را نصب کردی
۳. `wp-config.php` را از File Manager روی `600` بگذار
۴. ویرایشگرِ فایلِ وردپرس را ببند — در `wp-config.php`:
   ```php
   define('DISALLOW_FILE_EDIT', true);
   ```
   بدونِ این، هر کسی که یک بار به پنل برسد می‌تواند مستقیم کدِ
   افزونه‌ها را عوض کند.
۵. وردپرس و ووکامرس را به‌روز نگه دار — به‌روزرسانیِ خودکارِ
   نسخه‌های امنیتی را روشن بگذار
